# 🍽️ Recipely – Recipe Finder Website

**Recipely** is a modern, responsive recipe finder website that helps users discover recipes, explore different food categories, and learn how to prepare their favorite dishes. It provides a clean user interface with interactive recipe cards, detailed cooking instructions, and a dark mode for a better browsing experience.

## ✨ Features

- 🔍 **Recipe Search** – Find recipes quickly using the search functionality.
- 🍗 **Category Filtering** – Explore recipes based on food categories, such as chicken, soup, and more.
- 🥗 **Recipe Cards** – Browse recipes with images and essential information.
- 📖 **Recipe Details** – View ingredients and step-by-step cooking instructions.
- ▶️ **YouTube Integration** – Access recipe-related cooking videos.
- 🌙 **Dark Mode** – Switch between light and dark themes.
- ➕ **Show More Recipes** – Load more recipes and explore additional dishes.
- ⏳ **Loading Animation** – Get visual feedback while recipes are loading.
- ⚠️ **Error Handling** – Display appropriate messages when recipes cannot be found or loaded.
- 📱 **Responsive Design** – Enjoy a smooth experience on desktops, tablets, and mobile devices.
- 🎨 **Modern UI** – Clean layouts and interactive elements for easy navigation.

## 🛠️ Technologies Used

## 🚀 Getting Started

Follow these steps to run Recipely locally on your computer.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/EJathinReddy/Recipely.git
```

**2. Navigate to the project directory**

```bash
cd Recipely
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the website.

> If your project uses Create React App instead of Vite, use `npm start` to launch the development server.

## 💡 How It Works

1. Open Recipely in your browser.
2. Search for a recipe or browse available food categories.
3. Select a recipe card to view its details.
4. Check the ingredients and follow the cooking instructions.
5. Open the associated YouTube video, when available.
6. Switch to dark mode or explore more recipes as needed.
